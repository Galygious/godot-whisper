This addon uses the ONNX INT8 conversion distributed by the Sherpa-ONNX
project. Conversion/quantization changes the original model's representation.
Model package:
https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8.tar.bz2

No additional model training or weight modifications were performed by this
fork. File and source archive SHA256 values are in parakeet/dependencies.json.
The model is distributed as a separate release asset, not committed to Git.

Test audio (JFK speech): derived from whisper.cpp/samples/jfk.wav in the
upstream ggml-org/whisper.cpp project; converted from PCM16 to float32 for
the test runner. It is not included in the addon runtime's microphone input.
